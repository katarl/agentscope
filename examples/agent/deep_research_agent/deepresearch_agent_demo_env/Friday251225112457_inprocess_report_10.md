### 城市数据治理工程白皮书：一个面向城市级数据要素市场化配置的综合性治理框架

- 本白皮书由中国电子信息产业集团有限公司与清华大学数据治理工程联合课题组于2021年8月发布，旨在系统性地从安全、法律、技术、经济和制度等方面对城市数据治理开展理论研究和实践探索，为城市数据治理工作提供理论参考和实践指引。白皮书指出，现代数字城市建设是推进国家治理体系和治理能力现代化的关键行动，但当前面临的主要困难是如何高效、安全、合法合规地利用数据。这需要同时解决数据本身及开发利用过程中的安全、隐私问题，以及效率和标准化问题。在此背景下，白皮书围绕数据安全和数据要素，首次提出了一个综合性的治理框架。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf] 白皮书的主体内容分为四大部分：形势与意义、现状与问题、总体目标与思路，以及解决方案。在形势与意义部分，白皮书阐明了数据作为新生产要素的地位，释放其价值是数字社会发展的必然规律，也是我国把握新发展阶段、贯彻新发展理念、构建新发展格局的内在要求和关键支撑。它区分了数字经济1.0时代（政府推动，数据资源化利用）和2.0时代（市场配置，数据要素化配置），强调了数据要素市场化对于实现效率倍增、安全倍增和财富倍增的重要性。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]

- 白皮书在“现状与问题”部分对当前数据治理的多个维度进行了深入分析。在数据应用方面，呈现出政府想法多但落地路径少、企业需求旺盛但灰色供给活跃、社会共识广泛但协同机制缺乏的特点。在数据交易方面，自2014年以来我国已建成多个大数据交易所，交易模式多样，但主要以撮合和佣金分成模式为主，且正进入以区域性和国际性为特征的第二轮建设爆发期。在数据治理技术方面，技术快速演进，呈现出智能化、多样化和应用开发敏捷化的特征。在数据安全方面，我国数据安全体系仍部分建立在国外技术之上，存在“卡脖子”风险；同时，安全建设正从单体安全向整体安全转变，并面临多部门监管的现状。在法律法规方面，我国处于与欧美并行和跟随发展的状态，相关法制体系正在形成，但合规要求增加且执法存在自由裁量空间。在组织运行体系方面，政策区域化特征明显，数据主管部门性质和职能差异大，运营主体的商业模式仍在探索中。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf] 基于上述现状，白皮书总结了六大核心问题：数据有效供给不足、数据要素市场缺位、技术体系尚不完善、安全问题日益严峻、法律体系亟待健全、制度管理体系滞后。造成这些问题的主要原因被归结为三大矛盾未能有效破解：数据流通与数据安全的矛盾、数据资源开发利用的紧迫性与数据资产化体系建设的滞后性的矛盾、数据供需两旺与数据要素市场缺位的矛盾。这些矛盾阻碍了数据要素潜能的释放，难以支撑治理现代化、经济高质量发展和民生服务提升的目标。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]

- 为了破解上述难题，白皮书在“总体目标与思路”部分提出了创新的核心理念和模型。总体目标是通过创新制度、市场以及技术体系，将数据资源加工为可析权、可计量、可定价且风险可控的初级产品，促进数据的安全流通与高效配置，实现发展与安全的有机统一。其核心创新在于提出了“数据元件”的概念。数据元件是通过对数据脱敏处理后，由若干字段形成的数据集或由关联字段通过建模形成的数据特征，它作为连接数据供需两端的“中间态”，实现了原始数据与数据应用的“解耦”，从而破解“安全与流通对立”的难题。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf] 围绕数据元件，白皮书提出了两大核心理念。在数据要素方面，核心理念是“打造‘一库双链’，培育三级市场”。“一库”指建设全自主、高安全的“数据要素金库”（数据金库），作为数据要素运行的安全底座，用于存储核心数据、重要数据及数据元件。“双链”指以数据元件为中心，实现“数据资产链”（数据资源-数据元件-数据产品的形态转化）和“数据价值链”（数据在挖掘过程中价值不断释放）的融合。“三级市场”则指催生出的数据资源市场、数据元件市场和数据产品市场，分别对应数据归集、元件交易和产品服务环节。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf] 在数据安全方面，核心理念是“关键数据入库、双向风险隔离、三级安全管控”。“关键数据入库”强调将核心和重要数据归集到自主安全的数据金库。“双向风险隔离”指通过数据元件解耦，隔离数据从资源端到应用端的泄露风险以及从应用端到资源端的滥用风险。“三级安全管控”则指围绕技术环境、管理制度、流程审计三个方面，对数据源、数据元件、数据产品进行全方位安全管控。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]

- 白皮书进一步构建了“数据+模型”的数据要素化三级模型，为核心理念提供理论支撑。第一级是数据元件模型，数学描述为X = f(d1, d2, …, dn)，其中d是原始数据，f是模型函数，X是数据元件。该模型函数消除了原始数据的隐私安全风险，使数据元件成为可安全流通、可定价的标的物。第二级是数据应用模型，描述为Y = F(x1, x2, …, xm)，其中X是数据元件，F是应用算法模型，Y是数据应用。该模型旨在满足城市治理、民生服务等具体场景的个性化需求。第三级是定价与安全审核模型。定价模型基于数据元件的信息价值，该价值由元件体量、数据质量和信息密度共同决定，并提出了具体的数学评估公式。在此基础上，数据元件交易可采用议价（基于成本、信息价值和领域调节系数）和竞价（基于市场评估价和调节因子）两种机制。安全审核模型则采用函数S(X) = f(O, M, R)，对原始数据资源安全审核(O)、数据元件模型安全审核(M)和数据元件安全审核(R)进行综合判定，只有全部通过才允许流通。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf] 基于上述模型，白皮书描绘了完整的治理框架：在政府监管下，数据运营服务中心从各类数据源归集数据，委托数据金库专营商将原始数据转化为数据资源；数据元件开发商对数据资源进行开发形成数据元件，并通过数据元件市场交易；数据应用开发商购买数据元件，开发成面向最终用户的数据产品和服务。整个流程由技术路径、制度安排和市场体系共同支撑。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]

- 在“解决方案”部分，白皮书提出了以“制度+市场+技术”三点互为支撑的“1144”总体实施架构。第一个“1”是构建一个数据金库，基于全自主的PKS底座、中国电子云及高标准安全体系，建设包含数据仓库和数据元件仓库的物理隔离数据中心。第二个“1”是建立一套数据要素操作系统，包括数据清洗治理平台、数据资源管理平台、数据元件管理平台和数据流通平台，用于调度管理数据要素化全流程及金库资源。第一个“4”是涵养治理现代化、高质量发展、民生服务、科技创新四大应用生态。第二个“4”是建设以组织架构、管理制度、法律法规、安全管理为核心的四大制度体系。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf] 技术体系方案详细阐述了各组件功能。数据归集系统实现多源异构数据的实时与离线归集。数据金库采用物理分层隔离机制，确保“数据可用不可见”，其逻辑架构包含数据仓库（统一数据模型、基础层、资源层）和数据元件仓库。数据要素操作系统各平台分别负责数据清洗治理、资源管理、元件开发与全生命周期管理、以及元件交易流通。全栈式数据安全防护体系涵盖本质安全（网络、系统、终端、应用、密码基础设施）、过程安全（身份与访问控制、数据全生命周期安全防护、监测响应与审计）以及数据治理标准体系（数据清洗治理、数据要素、数据流通三类标准）。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]

- 制度体系方案是白皮书的另一大支柱。在组织机构设计上，明确了九类关键角色及其职责：1) 由市领导牵头的决策机构（领导小组）；2) 制定规划政策、实施监督管理的数据监管机构；3) 提供技术决策指导的数据治理专家组；4) 从事规划研究的数据研究咨询机构；5) 进行专业评定的评估机构；6) 政府授权下统一运营数据、管理交易平台的数据运营服务中心；7) 以国资网信企业为主、提供IT运维支撑的数据金库专营商；8) 开发数据元件的数据元件开发商；9) 开发数据产品和服务的数据应用开发商。这套设计体现了“政府主导、市场运作、多方参与”的原则。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf] 管理制度方面，提出了四大类文件：整体性制度文件（如总体规划）、面向数据的政策文件（如数据管理办法）、面向机构或主体的政策文件（如开发商管理办法）、以及其他专项政策文件（如安全管理办法）。法律法规建设部分提出了充分利用地方立法权或争取特别授权，为数据治理工程立法；构建个人信息合规体系，履行安全义务并优先开发匿名化产品；为政府主导的数据归集权提供法律依据；探索通过地方立法、行业规则或合同约定为数据财产权提供确权工具；以及通过准入制度、成本价管理公共数据、加强行政执法等方式保障数据财产流通交易市场的合法运行。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf] 安全管理则从组织架构（设立安全管理委员会和负责人）、安全管理制度（制定全生命周期管理办法）和安全监管制度（定期评估与监督整改）三个方面构建体系。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]

- 市场体系方案详细规划了三级市场的运作。数据资源市场的交易主体是拥有数据的政府、企业等，客体是原始数据集，交易规则主要通过协议购买和交换进行归集。数据元件市场的供给方是数据元件开发商，需求方是数据应用开发商，交易客体是可析权、可计量、可定价的数据元件，交易依托政府设立的数据运营服务中心的流通平台进行。数据产品市场的交易主体是应用开发商和终端用户，客体是基于数据元件开发的数据产品及服务，交易规则为供需双方依法达成协议后的点对点交易。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf] 三级市场采用差异化的定价机制：数据资源市场以成本法为主、收益法为辅；数据元件市场结合收益法和市场法；数据产品市场则完全由市场决定。为确保市场健康运行，还需配套市场监管体系，包括依据《反垄断法》加强数据反垄断监管、建立纠纷仲裁机制以及对违法违规交易行为进行合法合规监管。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf] 最后，白皮书强调了确保制度、市场和技术体系高效协同的运行机制，即充分发挥市场决定性作用（由数据运营服务中心推动市场体系建设）、政府主导作用（完善法律依据、搭建平台、制定政策、加强监管）和企业主体作用（加强数据开发利用、提供优质服务、推动技术创新、扩大市场规模）。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]
