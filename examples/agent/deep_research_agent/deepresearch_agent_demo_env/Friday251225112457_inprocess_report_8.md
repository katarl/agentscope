### 《城市数据治理工程白皮书》核心架构与实施方案的系统性解析

- 本白皮书由中国电子信息产业集团有限公司与清华大学数据治理工程联合课题组于2021年8月发布，旨在系统性地从安全、法律、技术、经济和制度等方面对城市数据治理开展理论研究和实践探索，为城市数据治理工作提供理论参考和实践指引。白皮书指出，现代数字城市建设面临的主要困难是如何高效、安全、合法合规地利用数据，这需要同时解决数据开发利用过程中的安全、隐私问题，以及效率和标准化问题。白皮书主体包含四部分内容：形势与意义、现状与问题、总体目标与思路，以及解决方案。在形势与意义部分，白皮书阐明了数据作为新生产要素的重要性，指出充分释放数据要素价值是数字社会时代发展的必然规律，更是我国把握新发展阶段的内在要求、贯彻新发展理念的实践路径和构建新发展格局的关键支撑。它将数字经济发展划分为两个阶段：1.0时代以“政府推动”为特点，强调数据资源化利用；2.0时代则以“市场配置”为特点，强调通过数据要素化配置实现经济社会效率、安全和财富的倍增。数据成为生产要素是生产力跃升的新动力，其价值源于减少不确定性、提升决策质量，是引领传统要素升级、提升全要素生产率、推动国家治理能力和“五位一体”协同发展的重要抓手。数据要素市场化为贯彻新发展理念提供了有效路径，并成为加快构建“双循环”新发展格局的关键支撑，通过打通生产、分配、流通和消费环节的堵点，优化资源配置。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]

- 白皮书详细分析了我国城市数据治理的现状与存在的核心问题。现状方面，呈现出“技术活跃、市场混乱、制度滞后”的特点。在数据应用上，政府想法多但落地路径少，企业需求旺盛但灰色供给活跃，社会共识强但协同机制不足。在数据交易上，自2014年以来我国已建成多个大数据交易所，交易模式多样，2020年后进入以区域性、国际性为特征的第二轮建设爆发期，但主要以撮合交易和佣金分成模式为主。在数据治理技术上，手段趋于智能化、多样化，应用开发趋向敏捷化。在数据安全上，我国体系仍建立在国外技术之上，存在“卡脖子”风险，整体安全建设得到重视，但呈现多部门监管多主体的特征。在法律法规上，我国处于与欧美并行跟随发展的状态，地方法制探索活跃，合规要求与法律责任不断加重。在组织运行上，政策区域化特征明显，数据主管部门性质和职能差异大，运营主体商业模式仍在探索。存在的问题归纳为六大方面：数据有效供给不足，共享融通壁垒未破，对传统要素的融合倍增价值难以释放，安全隐私保护标准阻碍了数据流转；数据要素市场缺位，缺乏合适的交易标的物导致交易规模有限，配套制度体系建设滞后；技术体系尚不完善，缺乏以城市为单位的规模化、工程化方案，缺乏统一的流通规约和技术标准；安全问题日益严峻，本质安全（底层技术自主可控）、过程安全（流通与隐私矛盾）、制度安全（权责不清）均面临挑战；法律体系亟待健全，立法滞后于数字经济发展，数据财产立法不足，企业数据立法显著滞后，部门利益牵制立法进度；制度管理体系滞后，主管部门职责不清，各方主体权责利不清晰，运营模式陈旧，数据运营机构支撑不明确。造成这些问题的深层原因在于三大矛盾未能破解：数据流通与数据安全的矛盾、数据资源开发利用的紧迫性与数据资产化体系建设的滞后性的矛盾、数据供需两旺与数据要素市场缺位的矛盾。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]

- 为破解上述矛盾，白皮书提出了数据治理工程的总体目标、核心理念与要素化模型。总体目标是通过创新制度、市场以及技术体系，将数据资源加工为可析权、可计量、可定价且风险可控的初级产品，促进数据的安全流通与高效配置，实现发展与安全的有机统一。其核心创新在于提出了“数据元件”的概念。数据元件是通过对数据脱敏处理后，由若干字段形成的数据集或由关联字段通过建模形成的数据特征，以及非结构化数据构成的数据集。它作为连接数据供需两端的“中间态”，实现了原始数据与数据应用的“解耦”，从而不能从数据产品中可逆获取原始数据，旨在破解“安全与流通对立”的难题。数据元件具有安全属性和价值属性。安全属性体现在风险隔离、安全审查和精准监管，能够实现数据泄露与滥用的“双向风险隔离”。价值属性体现在可析权、可计量、可定价，为数据流通交易奠定了基础。数据要素化的核心理念是“打造‘一库双链’，培育三级市场”。“一库”指建设全自主、高安全的“数据要素金库”（数据金库），作为数据要素运行的安全底座，用于归集和存储核心数据、重要数据及数据元件。“双链”指以数据元件为中心，实现“数据资产链”（数据资源-数据元件-数据产品的形态转化链）和“数据价值链”（数据价值在两次赋能中不断释放的链条）的融合。数据资源经过两次赋能释放价值：第一次赋能是将数据资源加工成数据元件，实现规模化开发和初步价值释放；第二次赋能是将数据元件通过业务建模打造成数据产品和服务，实现规模化应用和全面价值释放。“三级市场”指由此催生出的数据资源市场、数据元件市场和数据产品市场。数据安全的核心理念是“关键数据入库、双向风险隔离、三级安全管控”。“关键数据入库”指将核心数据和重要数据归集到自主安全的数据金库；“双向风险隔离”通过数据元件实现数据资源与应用的解耦，隔离泄露和滥用风险；“三级安全管控”指围绕技术环境、管理制度、流程审计对数据源、数据元件、数据产品进行安全管控。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]

- 白皮书构建了详细的数据要素化三级模型和治理框架。要素化模型包括数据元件模型、数据应用模型、定价与安全审核模型。数据元件模型数学描述为X=f(d1,d2,…,dn)，其中f是消除隐私安全风险的模型函数，X是数据元件，它保留了原始数据中的“信息”价值E(X)。数据应用模型描述为Y=F(x1,x2,…,xm)，将数据元件与应用算法结合，满足具体场景需求。定价与安全审核模型是核心，数据元件信息价值评估模型为I(X)=V(N)·Q(Z)·D(X)，其中V(N)是体量系数，Q(Z)是质量系数，D(X)是信息密度（基于香农信息论）。数据元件定价采用议价和竞价两种机制。议价交易中，协议价为基础价乘以收益率，基础价受元件成本、信息价值和领域调节系数影响。竞价交易中，市场指导价为市场评估价乘以市场调节因子，市场评估价由稀缺性(S)、时效性(T)、规模大小(N)、完整性(W)、历史参考价(Cp)等因素通过估价模型计算。数据元件安全审核模型为S(X)=f(O, M, R)，只有原始数据资源安全审核(O)、数据元件模型安全审核(M)和数据元件安全审核(R)均通过时，元件才能流通。基于上述模型，白皮书提出了全面的治理框架：在政府监管下，数据运营服务中心通过数据资源市场归集数据，委托数据金库专营商将原始数据转化为数据资源；数据元件开发商进一步开发形成数据元件；数据运营服务中心通过流通平台促成元件交易；数据应用开发商面向治理、经济、民生、科技等领域开发数据产品和服务。整个体系由技术路径、制度安排和市场体系共同支撑。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]

- 在解决方案部分，白皮书提出了“制度+市场+技术”三点互为支撑的“1144”总体实施架构。“1”是构建一个基于全自主PKS底座、中国电子云及高标准安全体系的数据金库，包含数据仓库和数据元件仓库，采用物理隔离和“数据可用不可见”机制。“1”是建立一套数据要素操作系统，包括数据清洗治理平台、数据资源管理平台、数据元件管理平台和数据流通平台，对要素化流程及金库资源进行调度管理。第一个“4”是涵养治理现代化、高质量发展、民生服务、科技创新四大应用生态。第二个“4”是建设以组织机构、管理制度、法律法规和安全管理为核心的四大制度体系。技术体系方案详细阐述了各组件：数据归集系统实现全方位全域数据归集；数据金库采用物理分层隔离的安全机制和增强型分布式融合架构；数据要素操作系统管理全流程；全栈式数据安全防护体系涵盖本质安全（网络、系统、终端、应用、密码基础设施）、过程安全（身份与访问控制、数据全生命周期安全防护、监测响应审计）以及数据治理标准体系（清洗治理、数据要素、数据流通三类标准）。制度体系方案中的组织机构设计尤为详尽，包括九类关键机构：决策机构（市领导牵头的领导小组）、数据监管机构（制定规划政策的政府部门）、数据治理专家组（专家学者提供咨询）、数据研究咨询机构（提供规划研究支撑）、评估机构（专业评估组织）、数据运营服务中心（政府授权的非营利运营管理枢纽）、数据金库专营商（国资网信企业提供技术支撑，原则上唯一）、数据元件开发商（多家，对数据资源进行开发）、数据应用开发商（多家，开发数据产品和服务）。管理制度分为整体性、面向数据、面向机构、专项政策四类文件。法律法规部分提出了充分利用地方立法权、构建个人信息合规体系、为政府数据归集权确权、为数据财产权提供确权工具、保障数据财产流通市场合法运行五大策略。市场体系方案明确了三级市场的交易主体、客体和规则，并提出了分级定价机制（资源市场以成本法为主、元件市场收益法与市场法结合、产品市场市场法）以及包含数据反垄断、纠纷仲裁、合法合规监管在内的市场监管体系。运行机制强调需发挥市场决定性作用（以数据运营服务中心为运营主体）、政府主导作用（完善法律、搭建平台、制定政策、加强监管）和企业主体作用（加强开发、提升服务、推动创新、扩大市场）三者的协同。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]
