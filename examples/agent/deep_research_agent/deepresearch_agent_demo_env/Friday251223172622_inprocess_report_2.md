## UNESCO《生成式人工智能在教育和研究中的应用指南》核心原则、具体建议与实施框架的详细分析

- 联合国教科文组织（UNESCO）于2023年9月发布的《生成式人工智能在教育和研究中的应用指南》是其首份关于该主题的全球性指导文件，旨在支持各国采取即时行动、规划长期政策并发展人力能力，以确保对这些新技术采取以人为本的愿景。该指南基于人文主义愿景，提出了规范生成式人工智能工具的关键步骤，包括强制保护数据隐私，以及为与生成式人工智能平台的独立对话设定年龄限制。为了指导在教育和研究中正确使用这些工具，该指南提出了一种以人为代理且适合年龄的伦理验证和教学设计过程方法。指南深入探讨了生成式人工智能是什么及其工作原理，介绍了多样的可用技术和模型；识别了围绕人工智能（总体而言）和生成式人工智能（具体而言）的一系列有争议的伦理和政策问题；讨论了在寻求基于以人为本的方法（确保合乎伦理、安全、公平且有意义的使用的）规范生成式人工智能时需要审查的步骤和关键要素；提出了可采取的措施，以制定连贯、全面的政策框架来规范生成式人工智能在教育和研究中的使用；探讨了在课程设计、教学、学习和研究活动中创造性使用生成式人工智能的可能性；并探索了生成式人工智能对教育和研究的长期影响。该指南以教科文组织《人工智能伦理问题建议书》（2021年）和《北京共识——人工智能与教育》（2019年）为基础，倡导人的能动性、包容、公平、性别平等以及文化和语言多样性。指南还响应了教科文组织于2023年5月召开的首次全球生成式人工智能部长级圆桌会议表达的关切。指南规定，在课堂中使用人工智能工具的年龄限制应为13岁，并呼吁就这一主题开展教师培训。该指南开篇解释了生成式人工智能的定义及其工作原理，接着阐述了生成式人工智能引发的争议及其对教育的影响，尤其是它如何加剧数字数据鸿沟，指出当前的ChatGPT模型训练以在线用户的数据为基础，而这些数据反映的是发达国家的价值观和主流社会规范。指南随后提出了各国规范生成式人工智能应采取的7个关键步骤，并为在教育和研究中以符合伦理要求的方式应用有关技术建立政策框架，包括采用全球、区域或国别数据保护和隐私标准。教科文组织在2023年6月示警，在学校中使用生成式人工智能的速度太快，缺乏公共监督、审查或规范，其发布的一份文件显示，在课堂中使用生成式人工智能工具比出版新教科书所需的授权更少。因此，指南的发布是为了应对有关技术所引发的挑战，确保秉持以人为本的原则，帮助政策制定者和教师从学生的基本利益出发，充分发挥人工智能潜能。[Citation](https://www.unesco.org/en/articles/guidance-generative-ai-education-and-research) [Citation](https://www.unesco.org/zh/articles/jiaokewenzuzhigeguoxujinkuaiguifanshengchengshirengongzhinengdexiaoyuanyingyong)

- 该指南的核心实施框架强调培养师生的人工智能能力。培养学生尤其是中小学生的人工智能能力对确保学生安全、符合伦理和有意义地应用人工智能至关重要。然而，截至2022年中，全球只有约15个国家制定并通过国家认可的中小学人工智能课程。随着生成式人工智能的迅速推广应用，培养面向所有人的基础性人工智能素养的需求更加迫切。为此，联合国教科文组织正在研制的“中小学生人工智能能力框架”，从“能力表现”和“能力层面”两个维度界定可通过课堂教学和课外课程结合的方式培养的中小学生人工智能能力。能力表现维度包括“人工智能观念”、“人工智能伦理”、“人工智能底层技术与应用”、“人工智能系统设计”；能力层面维度则从对相关知识、技能和情感态度的“理解”、“应用”和“创造”三个方面界定学生的能力表现。与此同时，联合国教科文组织在组织研制中小学教师人工智能能力框架，旨在引导各国制定相关的教师培训方案。这些能力框架是落实指南的关键，旨在分析人工智能的潜力和风险，以促进其安全、符合伦理、包容且负责的应用。教科文组织强调，各国在人工智能领域的投入应利用额外资源，而非挪用现有教育经费，因为在全球范围内，每4所小学中仍有1所尚未通电，60%的学校无法连接互联网，建设管理完善、设备齐全的学校，培养训练有素、待遇优厚、充满使命感的教师队伍，应始终作为基本需求优先考虑。指南的实施需要考虑到这些基础设施和资源的现实差距。[Citation](https://openedu.sou.edu.cn/upload/qikanfile/202401222229478275.pdf) [Citation](https://www.unesco.org/zh/articles/jiaokewenzuzhi2025nianguojijiaoyurijujiaorengongzhineng)

- 指南的发布背景和后续发展揭示了国际社会对AI教育治理的持续关注与行动。教科文组织将人工智能定为2025年国际教育日主题，以就这一技术在教育中的地位展开全球探讨，并计划在巴黎和纽约召开会议，以及举办网络研讨会。这反映了生成式人工智能教育应用的全球趋势及其引发的政策摇摆。在高收入国家，超过2/3的中学生已使用生成式人工智能工具完成作业，教师们也越来越越多地借助人工智能备课和评估学生作品，传统上由教师和专家负责的学业规划与录取流程也正逐渐被人工智能主导。然而，教育行业实践仍然缺乏清晰指导。教科文组织2023年5月对450所学校的调查显示，仅10%的学校和大学对人工智能的使用制定了正式框架。到2022年，仅7个国家为教师制定了人工智能相关的框架或培训方案，15个国家将人工智能培训目标纳入国家课程体系。与此同时，越来越多的国家开始对课堂中新兴技术的使用设限。教科文组织最新数据显示，截至目前，已有近40%的国家颁布法律或政策禁止在学校使用手机，而在2023年7月，这一比例仅为24%。这种矛盾状态凸显了指南提出的政策框架的紧迫性。指南呼吁各国政府通过制定法规、培训教师等，规范生成式人工智能的教育应用，这与其他国家和地区的政策动向一致，例如日本发布《初等中等教育阶段应用生成式人工智能的暂行指南》，建议学校小范围尝试使用生成式人工智能，并注意验证其应用效果；澳大利亚发布《澳大利亚学校生成式人工智能框架草案》，鼓励学校工作人员、教师和学生“安全且合乎道德”地使用生成式人工智能；中国国家网信办等七部门联合公布《生成式人工智能服务管理暂行办法》，鼓励生成式人工智能技术在各行业、各领域的创新应用。这些政策的发布显示了在政策限度内有序开放生成式人工智能教育应用是必然趋势，而UNESCO的指南为各国提供了一个基于全球共识的、以人为本的参考基准和行动路线图。[Citation](https://openedu.sou.edu.cn/upload/qikanfile/202405281816526939.pdf) [Citation](https://www.unesco.org/zh/articles/jiaokewenzuzhi2025nianguojijiaoyurijujiaorengongzhineng)
