# 北京大学数据治理体系结构化摘要

## 一、组织架构框架

### 1.1 顶层决策机构
- **北京大学网络安全和信息化委员会（网信委）**：网信工作最高决策机关
- **网络安全和信息化工作小组**：加强协调落实的执行机构

### 1.2 日常管理机构
- **网络安全和信息化委员会办公室（网信办）**：正处级实体单位，网信委的日常办事机构
  - 挂靠党委办公室、校长办公室行使中枢职能
  - 按照管办分离、管建协同的工作机制
  - 代表学校行使统筹协调职能

### 1.3 专项工作机构
- **北京大学校务信息数据管理工作小组（数据小组）**
  - **组长**：分管网信工作的校领导
  - **副组长**：分管保密工作的校领导
  - **办公室（数据办）**：设在网信办，负责日常运行
  - **主要职能**：统筹推进学校数据治理工作，协调各部门数据共享

### 1.4 技术实施机构
- **计算中心**：行使开发建设和运行维护职能

## 二、政策法规体系

### 2.1 网络安全管理制度
- **《北京大学网络安全管理办法（试行）》（2019年）**
  - 统筹网络技术安全和信息内容安全
  - 划定网络安全的内容和边界
  - 明确组织机构的职责分工和权责
  - 建立防御、监测、响应、处置全流程保障体系
  - 覆盖校内各单位、各类人员、各类信息系统

- **《北京大学官方新媒体平台日常管理及应急处置规程》（2020年）**
  - 明确官方新媒体平台的范畴
  - 规定管理机制和应急流程

- **《北京大学网站管理办法》（2021年修订）**
  - 明确各单位职责
  - 规范网站建设、信息发布、日常运行及监督检查
  - 提高网站安全保障能力

### 2.2 校务数据管理制度
- **《北京大学校务信息数据管理办法（试行）》**
  - 落实责任机制
  - 明确数据分级分类管理及使用制度
  - 规范数据全生命周期管理

- **《北京大学校务信息数据共享审批管理规定》**
  - 规范数据共享流程
  - 明确审批权限和程序
  - 保障数据安全合规共享

### 2.3 资源管理制度
- **《北京大学大型软件（非科研类）购置审批管理办法（试行）》**
  - 规范信息化资源采购和使用

## 三、实施策略与方法

### 3.1 "三位一体"建设模式
- **制度建设**：建立完整的规章制度体系
- **机构建设**：构建多层次组织架构
- **平台建设**：建设先进的技术支撑平台

### 3.2 数据治理核心目标
- 明确数据标准
- 提升数据质量
- 推进数据共享
- 保障数据安全
- 有效利用公共信息资源
- 切实维护师生个人信息权益

### 3.3 技术平台建设
- **数据4.0工艺平台**：采用业界先进技术平台
- **校务数据共享平台**：
  - 集成人员身份、资产设备、教学科研、学术支撑、行政运行、服务保障6大类数据
  - 共计10亿多条校务信息数据
  - 学校有史以来规模最大的校务数据集成共享平台

### 3.4 数据模型设计
- **"人（X）-事（Y）-时（Z）"三维立体数据互动结构模型**
  - 解决数据共享中的结构和模型问题
  - 实现数据动态关联和智能分析

## 四、挑战与解决方案

### 4.1 数字化转型面临的普遍挑战
1. **观念意识转变**
   - 多数师生员工仍将信息化定位为"支撑"或"辅助"
   - 需要提升对信息化"引领"作用的认识

2. **制度体系转换**
   - 原有机构设置、管理办法、运行模式形成强大惯性
   - 需要系统性制度重构

3. **资源利益调整**
   - 各单位原有信息系统和数据资源主导权需要重新分配
   - 涉及资源配置职权调整

4. **评价机制探索**
   - 缺乏成熟的网信投入评估评价体系
   - 需要建立科学的绩效评估标准

### 4.2 北京大学的具体应对策略
1. **顶层设计先行**
   - 2018年调整信息化建设领导小组为网信委
   - 2019年成立实体网信办
   - 建立校务数据管理工作小组

2. **制度建设保障**
   - 制定覆盖网络安全、数据管理、资源管理的完整制度体系
   - 通过制度明确职责、规范流程、落实保障

3. **机构协同推进**
   - 网信办代表学校行使统筹协调职能
   - 计算中心负责技术实施
   - 各部门密切合作，形成治理合力

4. **技术平台支撑**
   - 引进先进数据治理技术
   - 构建大规模数据集成平台
   - 解决技术水平和标准难题

## 五、绩效评估机制

### 5.1 经费投入机制
- **校级网信经费来源**：
  - "双一流"建设经费
  - 包括日常运维经费和年度项目经费
  - 由计算中心和网信办分别组织申报

- **二级单位网信经费来源**：
  - "双一流"建设经费
  - 科研经费
  - 自筹经费
  - 总体量远超校级网信经费

### 5.2 评估评价体系建设
- **评估目的**：
  - 加强对全校各级各类网信投入的风险评估和效果评价
  - 以标准规范体系建设弥补硬性管理措施的短板
  - 提高管理的弹性和韧性
  - 节约建设成本，提高投入效益

- **评估内容**：
  - 建设目标的完成度
  - 组织管理水平
  - 财务指标
  - 后评价指标：
    - 创新性
    - 业务量
    - 数据共享条数
    - 节约人力成本

### 5.3 评估条件准备
1. **组织基础**：
   - 网信委、网信工作小组、网信办、校务数据小组等机构正常运转
   - 治理组织机构不断完善

2. **规划基础**：
   - 《网信事业"十四五"发展规划》提供发展蓝图
   - 中长期发展规划已经明确

3. **治理基础**：
   - 逐步构建了具有北大特点的网络安全责任体系
   - 建立了信息化工作机制及校务数据治理模式
   - 为推进数字化、智能化转型夯实了基础架构

## 六、关键成功因素

### 6.1 战略高度重视
- 学校从战略角度出发，高度重视和支持校务数据治理工作
- 责成各单位密切合作，引进社会资源

### 6.2 系统协同推进
- 以推进数据共享为信息化工作枢纽
- 注重管理与技术相协调
- 加大相关部门协同力度

### 6.3 持续迭代完善
- 经过近两年的持续努力
- 同步开展制度建设、平台建设和机构建设
- 逐步构建具有北大特色的校务数据治理体系

### 6.4 资源保障充分
- "双一流"建设经费持续支撑
- 进入新时代以来，网信治理体系得以重新建构并不断完善
