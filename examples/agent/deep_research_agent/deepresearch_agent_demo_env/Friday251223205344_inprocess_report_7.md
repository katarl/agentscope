### **美国人工智能教育治理的政策框架、实施机制与挑战——基于行政命令14110及相关权威分析的综合报告**

- 美国拜登政府于2023年10月30日发布的第14110号行政命令（EO 14110）《安全、可靠和值得信赖的人工智能开发与使用》，标志着美国联邦层面人工智能治理进入了系统化、跨部门的全面行动阶段。该行政命令构建了一个覆盖八大政策领域的政府广泛治理框架，旨在通过联邦机构的领导、行业监管以及国际合作来引导负责任的人工智能发展与应用。这八大领域包括：安全与保障、创新与竞争、劳动者支持、人工智能偏见与公民权利考量、消费者保护、隐私、联邦人工智能使用以及国际领导力。值得注意的是，教育虽未被列为一个独立的顶级政策领域，但其相关要求被战略性地嵌入多个领域的具体行动中，特别是通过“联邦人工智能使用”和“劳动者支持”等章节，将人工智能技能培养和教育系统适应纳入国家人工智能能力建设的核心。行政命令明确指出，人工智能既蕴含巨大潜力也带来重大风险，负责任地利用人工智能应对紧迫挑战，需要政府、私营部门、学术界和民间社会的全社会共同努力。为协调实施，命令设立了白宫人工智能委员会，由总统助理兼政策副幕僚长担任主席，成员包括教育部、国家科学基金会（NSF）等超过28个联邦部门和机构的负责人，确保了教育相关行动在最高行政层面得到统筹。[[Citation](https://www.congress.gov/crs_external_products/R/PDF/R47843/R47843.3.pdf)]

- 在行政命令14110的具体条款中，教育部（ED）被赋予了明确且有时限的人工智能教育治理职责。根据国会研究服务局（CRS）的报告分析，该命令第8(d)节规定，教育部须在命令发布后365天内（即2024年10月29日前），开发适用于教育领域的人工智能使用资源、政策和指导。这项任务的一个核心交付成果是开发一套“教育工作者人工智能工具包”。该工具包旨在为K-12教育工作者提供实践性的资源、最佳实践和指导方针，帮助他们将人工智能技术安全、有效且合乎伦理地整合到教学和学习过程中。此举直接回应了在基础教育阶段普及人工智能素养、防范技术滥用风险的需求。此外，命令第5.2(a)(iii)节指示国家科学基金会（NSF）在540天内（截至2025年4月22日）额外建立至少四个新的国家人工智能研究所，以加强人工智能基础研究和人才培养。这些研究所与已有的机构网络共同构成了美国人工智能前沿研究与高等教育衔接的关键枢纽。命令还通过第6(c)节，鼓励国家科学基金会优先配置现有资源，支持与人工智能相关的教育和劳动力发展项目，突显了从基础研究到技能培养的全链条支持思路。[[Citation](https://www.congress.gov/crs_external_products/R/PDF/R47843/R47843.3.pdf)]

- 行政命令14110高度重视人工智能可能加剧社会不平等和侵犯公民权利的风险，其治理框架内包含了强有力的伦理规范维度，这对教育领域的应用具有直接指导意义。命令第7节专门针对“人工智能偏见与公民权利考量”，承认人工智能模型可能固化偏见，其部署可能导致公民权利受到侵害。为此，该节规定了多项具体行动。例如，司法部（DOJ）被要求在90天内召集各机构和监管机构，讨论如何利用现有权力防止算法和人工智能相关的歧视，并考虑改进外部利益相关者参与以及开发额外的培训、指导和资源。此外，命令要求劳工部（DOL）在365天内发布面向联邦承包商的指南，指导其防止在招聘中使用的人工智能系统产生偏见。虽然这些条款并非全部专门针对教育场景，但它们为教育机构采购或使用涉及招生、评估、学生服务的人工智能系统提供了普适性的合规与伦理框架。命令明确将“公平”列为八大指导原则之一，强调必须解决人工智能系统可能放大现有不平等或引入新形式歧视的风险，这要求教育领域的人工智能工具和应用在设计、开发和评估阶段就必须嵌入公平性审查和偏见缓解机制。[[Citation](https://www.congress.gov/crs_external_products/R/PDF/R47843/R47843.3.pdf)] [[Citation](https://www.rand.org/content/dam/rand/pubs/perspectives/PEA3300/PEA3379-1/RAND_PEA3379-1.pdf)]

- 为系统化地提升联邦政府的人工智能能力并辐射至全社会，行政命令14110在“联邦人工智能使用”部分（第10节）部署了一系列雄心勃勃的机构改革与人才建设计划，这些构成了美国人工智能教育治理中“政府端”能力建设的基础。根据CRS报告，命令要求《首席财务官法案》涵盖的各机构在管理和预算办公室（OMB）发布相关指南后的60天内，必须任命一名“首席人工智能官”（CAIO），负责协调本机构的人工智能使用、促进创新并管理相关风险。同时，各机构还需建立“人工智能治理委员会”或功能类似的机制。在人才方面，命令指示科技政策办公室（OSTP）和OMB在45天内制定一项“激增人工智能人才”的计划，并创建一个由副幕僚长、OSTP和OMB共同领导的“人工智能与技术人才工作组”，以加速和追踪联邦政府中人工智能人才的招聘。该工作组还需在180天内向总统报告进展情况并提出增加政府人工智能能力的建议。这些内部治理结构的建立和高端人才的引进，旨在确保联邦政府自身能够成为精通人工智能的实体，从而更有效地制定、监管和推广包括教育政策在内的各项人工智能政策。[[Citation](https://www.congress.gov/crs_external_products/R/PDF/R47843/R47843.3.pdf)]

- 行政命令14110的实施催生了更专门化、更聚焦的教育治理架构。2025年4月，特朗普政府签署了《推进美国青年人工智能教育》的行政命令，在此基础上成立了“白宫人工智能教育工作组”。根据白宫公告，该工作组的职责是执行相关政策并协调与人工智能教育相关的联邦努力，包括该命令中概述的各项行动。工作组被赋予的具体任务包括：寻求利用行业承诺并识别可用于为K-12人工智能教育提供资源的联邦资金机制（如可自由支配的拨款）；在命令发布90天内，确定现有的联邦人工智能资源（如NSF和美国农业部赞助的国家人工智能研究所），以支持与州和地方教育机构建立合作伙伴关系，改进人工智能教育。此外，该工作组正在计划并实施一项“总统人工智能挑战赛”，旨在激发美国青年对人工智能的兴趣。这些举措明确体现了“公私合作模式”（PPP）在人工智能教育治理中的应用，即联邦政府通过设立专门协调机构，引导和整合私营部门的资源（如行业承诺、技术专长）、联邦资金以及研究机构的成果，共同向地方教育系统输送能力和资源，以解决教育资源分配和师资培训等方面的挑战。[[Citation](https://www.whitehouse.gov/presidential-actions/2025/04/advancing-artificial-intelligence-education-for-american-youth/)] [[Citation](https://www.ai.gov/initiatives/education)]

- 独立智库的研究为理解行政命令14110教育条款的实施挑战和未来方向提供了重要补充。兰德公司（RAND）在2024年发布的报告《引领人工智能：为美国民事和军事领导人提供的加强人工智能劳动力的见解》中指出，尽管命令强调了提升联邦劳动力人工智能技能的重要性，但有效整合人工智能面临多重组织性挑战。报告认为，对于人工智能在教育领域发挥效能，学校系统本身必须进行转型。具体而言，学校政策需要重新调整，将掌握基础技能置于严格遵守年级水平标准之上。如果没有这种转变，人工智能工具将无法充分发挥潜力，教师将难以平衡个性化学习和课程覆盖。这揭示了课程标准与人工智能赋能个性化学习之间的潜在张力，是治理中需要解决的关键问题。此外，报告强调，中学后教育机构（包括培训和认证组织）需要与人工智能行业建立战略伙伴关系、重新设计课程并投资基础设施，以使教育与人工智能劳动力需求保持一致。为确保成功，这些机构还必须吸引多样化的学生，留住熟练的教师，并利用政府支持来克服障碍，在不断发展的人工智能领域保持竞争力。这些分析指出了超越具体工具开发、触及教育系统深层结构改革的治理需求。[[Citation](https://www.rand.org/content/dam/rand/pubs/perspectives/PEA3400/PEA3414-1/RAND_PEA3414-1.pdf)]

- 美国的人工智能教育治理呈现出明显的“全政府”和“全社会”参与特点，其框架不仅关注校内教育，更延伸至劳动力发展与国家安全维度。行政命令14110的第5节“创新与竞争”和第6节“劳动者支持”体现了这一广度。命令要求国务院（DOS）和国土安全部（DHS）在90天内简化寻求来美从事人工智能教育或工作的外国人的签证流程，并考虑制定新标准以吸引顶级人工智能人才。这表明治理框架将全球人才竞争视为人工智能领导力的基石。同时，命令指示经济顾问委员会（CEA）在180天内报告人工智能对劳动力市场的影响，并指示劳工部（DOL）报告各机构协助受人工智能影响的工人的能力。这反映了治理对人工智能可能带来的劳动力市场震荡的前瞻性关注，将教育、培训和劳动力转型政策紧密挂钩。从CRS报告列出的详细交付成果表来看，涉及教育部、NSF、劳工部等多个部门的行动在时间线上相互交织，构成了一个从基础研究（NSF研究所）、教育资源开发（ED工具包）、技能培训（劳工部项目）到人才吸引（国务院、DHS签证政策）的多维度、分阶段实施图谱。这种综合性的治理方法旨在确保人工智能教育的成果能够有效转化为国家创新能力和经济竞争力。[[Citation](https://www.congress.gov/crs_external_products/R/PDF/R47843/R47843.3.pdf)]
