# 北京大学数据治理体系详细分析

## 一、组织架构

### 1.1 数据治理组织体系
- **最高决策机构**：北京大学网络安全和信息化委员会（网信委）
- **协调执行机构**：网络安全和信息化工作小组
- **日常办事机构**：网络安全和信息化委员会办公室（网信办）
- **专门数据治理机构**：北京大学校务信息数据管理工作小组（数据小组）

### 1.2 校务信息数据管理工作小组组成
- **组长**：分管网信工作的校领导
- **副组长**：分管保密工作的校领导
- **办公室**：设在网信办，称为"数据办"，负责日常运行

### 1.3 职责分工
- **网信委**：网信工作最高决策机关
- **网信办**：行使统筹协调职能，代表学校行使统筹协调职能
- **计算中心**：行使开发建设和运行维护职能（管办分离、管建协同机制）

## 二、政策法规体系

### 2.1 核心数据治理政策
1. **《北京大学校务信息数据管理办法（试行）》**
   - 目的：明确职责、规范流程、落实保障
   - 内容：数据分级分类管理及使用制度

2. **《北京大学校务信息数据共享审批管理规定》**
   - 目的：规范数据共享流程
   - 内容：数据共享审批机制

### 2.2 相关配套政策
- **网络安全**：
  - 《北京大学网络安全管理办法（试行）》（2019年）
  - 统筹网络技术安全和信息内容安全
  - 建立防御、监测、响应、处置全流程体系

- **资源管理**：
  - 《北京大学大型软件（非科研类）购置审批管理办法（试行）》

- **新媒体管理**：
  - 《北京大学官方新媒体平台日常管理及应急处置规程》（2020年）

- **网站管理**：
  - 《北京大学网站管理办法》（2021年修订）

## 三、实施方法与技术架构

### 3.1 三位一体建设模式
1. **制度建设**：建立完善的政策法规体系
2. **机构建设**：构建专门的组织架构
3. **平台建设**：建设先进的技术平台

### 3.2 技术平台
- **平台类型**：数据4.0工艺平台（业界最先进）
- **数据模型**：人（X）-事（Y）-时（Z）三维立体数据互动结构模型
- **数据规模**：10亿多条校务信息数据
- **数据分类**：6大类
  1. 人员身份
  2. 资产设备
  3. 教学科研
  4. 学术支撑
  5. 行政运行
  6. 服务保障

### 3.3 实施路径
- 以推进数据共享为信息化工作枢纽
- 管理与技术相协调
- 加大相关部门协同力度

## 四、挑战与解决方案

### 4.1 数字化转型挑战（文中提及）
1. **观念意识转变**：
   - 挑战：信息化仍被视为"支撑"或"辅助"而非"引领"
   - 解决方案：加强宣传培训，提升数据素养

2. **制度体系转换**：
   - 挑战：原有机构设置、管理办法、运行模式形成强大惯性
   - 解决方案：顶层设计，机构调整，建章立制

3. **资源利益调整**：
   - 挑战：各单位各自为政，通过系统主导权体现资源配置职权
   - 解决方案：统一数据标准，集中共享，一数一源

4. **评价机制探索**：
   - 挑战：缺乏有效的评估体系
   - 解决方案：建立网信投入评估评价体系

### 4.2 数据治理具体挑战
- **技术水平和标准难题**：通过采用数据4.0工艺平台解决
- **管理共享问题**：通过三维立体数据互动结构模型解决

## 五、绩效评估机制

### 5.1 网信投入评估评价体系
- **目的**：加强对全校各级各类网信投入的风险评估和效果评价
- **方法**：以标准规范体系建设弥补硬性管理措施的短板
- **效果**：提高管理的弹性和韧性，节约建设成本，提高投入效益

### 5.2 评估内容
1. **建设目标的完成度**
2. **组织管理水平**
3. **财务指标**
4. **后评价指标**：
   - 创新性
   - 业务量
   - 数据共享条数
   - 节约人力成本

### 5.3 经费机制
- **校级网信经费来源**："双一流"建设经费
  - 日常运维经费
  - 年度项目经费
- **二级单位网信经费来源**：
  - "双一流"建设经费
  - 科研经费
  - 自筹经费
- **特点**：二级单位网信经费总体量远超校级网信经费

## 六、治理成效

### 6.1 阶段性成果
- 构建了具有北大特点的网络安全责任体系
- 建立了信息化工作机制
- 形成了校务数据治理模式
- 为推进数字化、智能化转型夯实了基础架构

### 6.2 数据治理成果
- 实现了信息数据集成重构
- 提供了校务数据共享服务
- 实施了网信资源归口管理
- 明确了数据标准、提升了数据质量、推进了数据共享、保障了数据安全

## 七、战略定位

- 校务信息数据资源的治理共享被视为推动教育数智化转型发展的基本战略性任务
- 学校从战略角度出发，高度重视和支持校务数据治理工作
- 责成各单位密切合作，引进社会资源
- 在有效利用公共信息资源的同时，切实维护好师生个人信息权益
