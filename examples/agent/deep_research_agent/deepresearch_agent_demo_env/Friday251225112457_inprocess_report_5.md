## 清华大学数据治理研究中心的组织架构、研究内容与典型案例分析
- 清华大学社会科学学院下属的数据治理研究中心，其前身是2016年由政治学系自发建设的数据治理实验室，旨在服务于国家大数据战略和国家治理现代化战略。该中心在2020年6月经清华大学社会科学学院正式批文，升级为院属研究机构，并由政治学系代管，标志着其进入了新的发展阶段。中心的组织结构清晰，设有学术委员会、中心领导及行政与科研团队。学术委员会主席由清华大学社科学院党委书记、经济学研究所教授刘涛雄担任；中心主任由清华大学社科学院政治学系主任、教授张小劲担任；执行主任由清华大学社科学院副院长、政治学系长聘副教授孟天广担任。该中心服务于清华大学社科学院的学科建设和社会服务，与政治学系、社会科学学院的其他专业科系，以及计算机系、交叉信息研究院、公共管理学院等长期开展合作研究，形成了一个由20多位研究人员构成的跨学科科研团队。行政人员包括项目总监马絜和行政秘书王睿诗，博士后研究人员则来自中山大学、北京大学、清华大学、日本爱知大学等不同高校的博士，体现了人才背景的多样性。中心的核心使命是将清华大学社科学院多学科汇聚的科研优势、社会科学与数据科学的深度融合与国家治理现代化的战略需求相结合，构建跨学科研究团队，并推进清华大学与中央部委、地方政府、阿里巴巴、百度等政府部门与科技企业的交叉融合。其目标一方面是促进大数据政治学等新兴学科建设以服务学校“双一流”学科建设，另一方面是更好地服务国家和地方治理现代化，在数字政府、政务大数据、智能化治理等新兴领域形成“清华方案”。[https://www.dps.tsinghua.edu.cn/xsjs/yjjg/bjdqythyjzx.htm]
- 清华大学数据治理研究中心的研究内容聚焦于国家治理数字化转型下的计算政治学方向，自2015年酝酿启动以来，整合了社会科学、计算科学与数据科学等方向的学术资源。中心先后主持了两项国家社科基金重大项目：2016年由张小劲教授主持的“大数据驱动下的政府治理能力建设研究”和2018年由孟天广副教授主持的“基于大数据的智能化社会治理监测、评估与应对策略研究”。此外，中心还承担了多项纵向课题（如国家社会科学基金、国家自然科学基金、国家重点研发计划等）和横向课题，合作方包括民政部、退役军人事务部、住建部、中央网信办以及北京市、江苏省、湖北省等部委和地方政府，其相关成果曾获得多次领导批示，显示出较强的政策影响力。围绕学科建设与发展，研究中心组建了数字政府治理、智能社会治理、数据要素治理等多个跨学科团队，并出版了《过程导向的国家治理》、《智能治理导论》等著作。同时，中心积极探索计算社会科学学科体系建设，致力于利用大数据、机器学习、自然语言处理等新兴方法提出适用于社会科学研究的算法库、软件包和知识库，并建设计算社会科学数据平台和算法平台，以不断夯实交叉学科的发展基础。中心的研究工作强调将社会科学理论与国家治理、社会治理实践相结合，在大数据驱动社会治理创新、数字化国家能力、数据治理体系、政务大数据开放与应用等领域开展高质量的政策研究，以服务中央和地方政府决策咨询。[https://www.tsinghua.edu.cn/info/1182/110138.htm]
- 清华大学在数据治理领域的实践不仅限于理论研究，还深度参与了城市级数据治理工程的方案设计与实践探索。中国电子与清华大学数据治理工程联合课题组于2021年8月发布了《城市数据治理工程白皮书》，该白皮书首次系统地从安全、法律、技术、经济和制度等方面对城市数据治理开展理论研究和实践探索。白皮书提出了以“一库双链、三级市场”为核心的数据要素化理念和以“关键数据入库、双向风险隔离、三级安全管控”为核心的数据安全理念。其中，“一库”指的是建设全自主、高安全的“数据金库”作为底层运行支撑；“双链”是指打通数据资产链和数据价值链；“三级市场”是指培育数据资源、数据元件和数据产品三级市场。这一框架创新性地提出了“数据元件”作为连接数据供需两端的“中间态”，通过对数据脱敏处理后形成可析权、可计量、可定价且风险可控的数据集或数据特征，实现原始数据与数据应用的“解耦”，从而破解数据安全与流通对立的难题。白皮书还详细规划了包括技术体系、制度体系、市场体系和运行机制在内的完整解决方案。技术体系涵盖数据归集系统、数据金库、数据要素操作系统、全栈式数据安全防护体系等；制度体系则详细设计了组织机构（如决策机构、数据监管机构、数据治理专家组、数据运营服务中心等）、管理制度、法律法规和安全管理等内容。这一由清华大学深度参与制定的综合性治理框架，为理解高校研究机构如何将其理论成果转化为支撑地方乃至国家层面数据治理实践的“最佳实践”提供了极具价值的典型案例。[https://www.cestc.cn/webfile/upload/2021/08-23/14-49-050144-227767121.pdf]
- 清华大学公共管理学院的学者也从公共数据治理的角度，对国家数据基础制度的构建提出了见解，这反映了清华大学在数据治理政策研究方面的广度。清华大学公共管理学院孟庆国教授指出，以公共数据治理为抓手推动数据基础制度的构建与完善，是我国各级各部门加快释放数据要素价值的必然选择。他提出，兼顾公共数据的开发利用和安全保护必须构建以政府数据管理机构为核心，多方主体共同参与、各司其职的综合治理结构。其中，数据管理机构代表政府对公共数据进行管理，并对参与数据治理的企业和个人实施监管，推动落实网络安全、数据安全、个人信息保护等相关要求；公共部门作为数据的提供者和使用者，应遵守数据治理的各项规则和要求，保证数据质量、提出数据需求；数据运营商、研究支撑机构、数据交易机构等是公共数据运营过程中的重要主体，政府应在这些机构中占据主导权。整个治理和运营活动应以大数据平台为数据的流转枢纽，汇聚政府、社会的数据资源，提供安全、可信的数据清洗、加工环境，以支撑公共数据的高效运营。这一观点强调了政府在公共数据治理中的核心监管与主导角色，以及构建包含多利益相关方的治理结构的重要性，为高校数据治理研究如何对接国家宏观政策与制度设计提供了理论衔接。[https://www.ndrc.gov.cn/xxgk/jd/jd/202212/t20221220_1343707.html]
